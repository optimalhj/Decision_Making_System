# 구단 로고 이미지 넣는 곳

기본적으로 화면에는 **구단 상징색과 약칭으로 만든 오리지널 엠블럼**이 표시됩니다.
실제 구단 로고 이미지는 각 구단의 상표이므로 이 배포판에 포함되어 있지 않습니다.

수업에서 실제 로고를 쓰고 싶다면(교내 수업용 등 사용 권한이 있는 경우), 이 폴더에
**팀코드.확장자** 형식으로 이미지 파일을 넣으면 라이브 뷰어가 자동으로 그 이미지를 사용합니다.

지원 확장자: `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`

| 팀코드 | 구단 | 파일 예시 |
|---|---|---|
| `SS` | 삼성 라이온즈 | `SS.png` |
| `KT` | KT 위즈 | `KT.png` |
| `LG` | LG 트윈스 | `LG.png` |
| `HT` | KIA 타이거즈 | `HT.png` |
| `OB` | 두산 베어스 | `OB.png` |
| `NC` | NC 다이노스 | `NC.png` |
| `LT` | 롯데 자이언츠 | `LT.png` |
| `SK` | SSG 랜더스 | `SK.png` |
| `HH` | 한화 이글스 | `HH.png` |
| `WO` | 키움 히어로즈 | `WO.png` |

- 정사각형에 가까운 이미지가 가장 보기 좋습니다 (배경 투명 PNG 권장).
- 파일을 넣은 뒤 브라우저 새로고침만 하면 바로 반영됩니다 (서버 재시작 불필요).
- 파일이 없는 팀은 자동으로 기본 엠블럼이 표시됩니다.
- 이 기능은 서버로 띄우는 라이브 뷰어(`live_viewer.html`)에서만 동작합니다.
  파일로 직접 여는 리플레이 뷰어(`broadcast_viewer.html`)는 항상 기본 엠블럼을 씁니다.
